# ❌⭕ Tic-Tac-Toe (Morpion) - Java Console Game

A classic **Tic-Tac-Toe** game built in Java! Designed to run smoothly in the command line or packaged into a standalone `.exe` executable for Windows.

---

## 🚀 Features

* 🎮 **Interactive Gameplay:** Turn-based gameplay with input validation.
* 📐 **Aesthetic ASCII Board:** Clear, enlarged 3x3 grid display with row and column numbers for easy coordinate entry.
* 🖼️ **ASCII Art Display:** Dynamic title screens for Welcome, Victory, Defeat, and Draw outcomes.
* 🔄 **Replay System:** Press `R` at the end of a match to instantly start a fresh game without closing the terminal.
* 📦 **Executable Support:** Configured for export to `.jar` and wrapping into a Windows `.exe` application.
